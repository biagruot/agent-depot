```
Hey HN! I built AgentDepot to solve a problem I kept running into: finding quality AI coding agents is way too fragmented.

The Problem:
I use Cursor for coding with AI. To make it better, you need custom rules. But those rules are scattered across:
• Random GitHub repos (cursor-rules, awesome-cursor, etc.)
• Reddit threads (r/cursor)
• Discord servers (Cursor community)
• Twitter threads

Same problem exists for Claude Code, Windsurf, and other tools. There's no central directory.

What I Built:
A searchable directory covering 70+ agents across:
• Cursor (rules & workflows)
• Claude Code (agents & skills)
• Windsurf (rules & MCP servers)
• Replit (templates)
• MCP servers

Tech Stack:
• Next.js 16 with App Router
• Fuse.js for client-side fuzzy search (fast for <500 agents)
• Tailwind CSS 4 (playing with the new features)
• Static generation (no database - all data in TypeScript files)
• Deployed on Netlify

Why Static Data?
Initially considered PostgreSQL, but decided static data = faster builds, easier contributions (just edit TS files), and free hosting. Will migrate to database if we hit 500+ agents.

Design Decisions:
• Glassmorphism UI (because AI tools need to look premium)
• One-click copy install commands (most important action)
• URL parameter sync for shareable filters
• Mobile-first responsive

What's Next:
• CLI tool: `npx agentdepot search "react"`
• VS Code extension (search agents from editor)
• Community contributions (GitHub-based workflow)

Would love feedback on:
1. Architecture (static data vs database - where's the breakpoint?)
2. Search experience (too slow? missing features?)
3. What agents/rules do you wish existed?

Try it: https://agentdepot.dev

GitHub: https://github.com/agentdepot/agentdepot-agents (coming soon)
```

✅ Use high-quality screenshots
